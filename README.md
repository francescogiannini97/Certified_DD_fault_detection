# Certified data-driven fault detection using behavioral uncertainty quantification

This repository contains the Python code for the paper *Certified data-driven fault detection
using behavioral uncertainty quantification* by Francesco Giannini and Ivan Markovsky.

To reproduce the results, run

```
pip install -r requirements.txt
python run_all.py
```

Tested with Python 3.12.

If you use this code, please cite the paper (see `CITATION.cff`). License: Apache 2.0.
